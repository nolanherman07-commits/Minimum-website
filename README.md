# Nolan Herman, REALTOR® | Nestlewood Realty

## Files
- `index.html`: the website.
- `site-info.js`: **all of the info on the site** (name, phone, email, stats, bio, links, reviews,
  and which design to use). This is the only file you edit.
- `styles.css` and `script.js`: the design and the code that builds the page. No need to edit these.
- `images/`: logo, headshot and cover photo. To change a photo, upload a new one with the same file name.
- `designs.html`: a preview of all 3 designs with a Classic / Bold / Modern switch.

## Switching designs
In `site-info.js`, change `theme: "classic"` to `"bold"` or `"modern"`.
To preview without changing anything, add `?theme=bold` or `?theme=modern` to the end of the page link.

## Making a site for someone else
Copy the whole folder, swap the photos in `images/`, and update `site-info.js`.
